# 🤖 JavaScript
Detta är mitt första projekt inom JavaScript. Projektet innehåller lösningar på nio uppgifter där varje uppgift är strukturerad i varsin fil. Varje fil är döpt efter uppgiftens namn, visar att det är en JavaScript-fil och innehåller en inledande kommentar och beskrivning.
